1.วัตถุประสงค์ของการสร้างแอป  
เพื่อพัฒนาแอปพลิเคชันที่ช่วยผู้ใช้ คำนวณและประเมินค่า BMI ได้อย่างสะดวก รวดเร็ว และลดความยุ่งยากในการคำนวณด้วยตนเอง  
เพื่อพัฒนาแอปพลิเคชันที่สามารถ คำนวณค่า BMR เพื่อให้ผู้ใช้ทราบค่าพลังงานพื้นฐานที่ร่างกายต้องการในแต่ละวัน  
เพื่อให้ผู้ใช้สามารถนำผลที่ได้ไปใช้เป็น ข้อมูลประกอบการดูแลสุขภาพเบื้องต้น เช่น การติดตามน้ำหนักและการวางแผนดูแลตนเอง  
เพื่อสร้างโปรแกรมที่ใช้งานง่าย โดยผู้ใช้เพียงกรอกข้อมูลที่จำเป็น ระบบจะคำนวณและแสดงผลให้อัตโนมัติ  
//  
2.กลุ่มเป้าหมาย
นักเรียนและนักศึกษา ที่ต้องการเรียนรู้เกี่ยวกับ BMI, BMR และการดูแลสุขภาพ  
บุคคลทั่วไป ที่ต้องการตรวจสอบค่า BMI และ BMR ของตนเองในเบื้องต้น  
ผู้ที่สนใจดูแลสุขภาพ และต้องการติดตามข้อมูลเกี่ยวกับน้ำหนักและพลังงานพื้นฐานของร่างกาย  
ผู้ที่ต้องการเครื่องมือคำนวณสุขภาพที่ ใช้งานง่ายและไม่ซับซ้อน  
//  
3.ฟังก์ชันของแอป

ฟังก์ชันที่ 1: คำนวณและประเมินค่า BMI
ผู้ใช้กรอกน้ำหนักและส่วนสูง จากนั้นระบบจะนำข้อมูลมาคำนวณค่า BMI และแสดงผลการประเมินตามเกณฑ์ ได้แก่ ผอม ปกติ ท้วม และอ้วน  

ฟังก์ชันที่ 2: คำนวณค่า BMR
ผู้ใช้กรอกข้อมูลน้ำหนัก ส่วนสูง อายุ และเพศ จากนั้นระบบจะคำนวณค่า BMR เพื่อแสดงค่าพลังงานพื้นฐานที่ร่างกายต้องการต่อวันในหน่วยกิโลแคลอรี
